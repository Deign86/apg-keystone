# APG Terminal

All-in-one admin terminal for Alpha Premier Group, combining Check Vouchers, Billing Statements and the ID Maker around one shared Directory, with an Activity Log.

This is the proof of concept from 2026-10-27, restored from the published artifact (https://claude.ai/artifact/8wDi7hq2EM9oQBfWS46uyb). It is a single static page: open `index.html` in a browser.

## Status

- Sample PHP data only; state is kept in the browser's `localStorage` (key `apg-terminal-state`).
- Export buttons are stubs.
- Next step: turn it into a native macOS/Windows app.

## Look

Uses the APG "Dark Gold Luxury" house style shared with the attendance tracker and website: Orbitron headings, Poppins body, gold `#c6a254` on near-black.
